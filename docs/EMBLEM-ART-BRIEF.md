# Emblem Art Brief — 27 illustrated emblems

Proven in-app (see session tests): the artwork sits on a near-black disc
inside the app's existing rarity metal rim + gloss. The art must be a
**character/object cutout on a transparent background** — the app supplies
the ring and the background.

## Format rules (every image)

- **PNG with real transparent background** — no painted backdrop, no circle,
  no ring, no frame, no text, no drop shadow baked in
- **1024×1024**, single subject, roughly centered (exact centering is done
  automatically by script — center of mass alignment)
- Consistent style across the whole set: kawaii chibi, big glossy eyes where
  the subject has a face, blush cheeks, clean dark outlines, soft painted
  shading, tiny sparkles allowed
- Higher rarity → slightly richer effects (glow, particles, gold accents);
  commons stay simple and clean

## Base prompt template

> Cute kawaii chibi [SUBJECT], big glossy amber eyes, blush cheeks, soft
> painted illustration with clean dark outlines, gentle highlights, tiny
> sparkles, single centered character, transparent background, no circle,
> no frame, no text

## Delivery

Send in any batches; name them by the file column (or just say which is
which). Processing per image (background-check, center-of-mass alignment,
webp conversion) is scripted — no manual cleanup needed on your side.

New emblems beyond these 27 (pizza, donut, rocket, shield, snowflake, etc.)
are phase 2 — same spec, new catalog entries; list lives in the plan file.
